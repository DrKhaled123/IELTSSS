## Getting Started

### System Requirements

**Desktop:**
- Chrome 90+, Firefox 88+, Safari 14+, Edge 90+
- 4GB RAM minimum
- Modern internet connection

**Mobile:**
- iOS Safari 14+, Chrome Mobile 90+
- Android Chrome 90+
- 2GB RAM minimum
- Stable internet connection

### First Time Setup

1. **Open the App**
   - Navigate to the app URL in your browser
   - Allow microphone permissions when prompted

2. **Create Your Profile**
   - Click on your name in the top-right corner
   - Set your German proficiency level (A1-C2)
   - Choose your native language for translations

3. **Take the Placement Test**
   - Recommended for personalized learning path
   - Takes 10-15 minutes
   - Covers vocabulary, grammar, and comprehension

### Account Creation

**Benefits of Creating an Account:**
- Progress synchronization across devices
- Personalized learning recommendations
- Achievement system and badges
- Access to premium features

**Steps:**
1. Click "Sign Up" in the navigation
2. Enter your email and create a password
3. Verify your email address
4. Complete your profile setup

## PDF Master

### Overview

PDF Master allows you to upload German learning materials and convert them into interactive lessons.

### Supported File Types

- **PDF Documents** (.pdf)
- **Text Files** (.txt, .doc, .docx)
- **Maximum File Size**: 50MB
- **Recommended Size**: Under 10MB for best performance

### Uploading PDFs

1. **Click "Upload PDF" button**
2. **Select your German learning file**
3. **Wait for processing** (typically 30-60 seconds)

## Troubleshooting

### Common Issues

#### Audio Problems

**No Sound:**
1. Check device volume
2. Verify browser permissions
3. Test with headphones
4. Restart browser

**Poor Audio Quality:**
1. Check internet connection
2. Lower audio quality setting
3. Clear browser cache
4. Update browser

#### Speech Recognition Issues

**Microphone Not Working:**
1. Check microphone permissions
2. Test microphone with other apps
3. Use external microphone
4. Restart device

**Poor Recognition:**
1. Speak clearly and slowly
2. Reduce background noise
3. Use quiet environment
4. Check microphone position

#### PDF Processing Problems

**Upload Fails:**
1. Check file size (max 50MB)
2. Verify file format (.pdf)
3. Try different browser
4. Check internet connection

**Processing Takes Too Long:**
1. Large files take more time
2. Check internet speed
3. Try with smaller file first
4. Contact support if needed

#### Progress Not Saving

**Sync Issues:**
1. Check internet connection
2. Verify login status
3. Refresh browser page
4. Clear browser cache

**Lost Progress:**
1. Check if using correct account
2. Look in offline storage
3. Contact support with details
4. Check device settings

### Performance Issues

**App Running Slow:**
1. Clear browser cache
2. Close other browser tabs
3. Restart browser
4. Check device memory

**Loading Problems:**
1. Check internet speed
2. Disable browser extensions
3. Try different browser
4. Restart device

## Quick Reference

### Keyboard Shortcuts

- **Space**: Play/pause audio
- **Enter**: Submit answer
- **Tab**: Next field
- **Shift+Tab**: Previous field
- **Esc**: Close modal/popup

### Study Tips

1. **Consistent Daily Practice**: 15-30 minutes daily
2. **Mix Learning Methods**: Combine visual, audio, writing
3. **Review Regularly**: Use spaced repetition
4. **Practice Speaking**: Active recall improves retention
5. **Track Progress**: Monitor improvement and adjust

### Recommended Study Schedule

**Beginner (A1-A2):**
- 20 minutes vocabulary
- 15 minutes grammar
- 10 minutes reading
- 10 minutes writing
- 5 minutes speaking

**Intermediate (B1-B2):**
- 25 minutes vocabulary
- 20 minutes grammar
- 15 minutes reading
- 15 minutes writing
- 10 minutes speaking

**Advanced (C1-C2):**
- 20 minutes vocabulary review
